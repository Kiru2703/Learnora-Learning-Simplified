# Learnora – Learning Simplified 📚✨

Learnora is a web application designed to simplify learning by providing a clean, intuitive interface and seamless backend integration. Built with a focus on accessibility, scalability, and user experience, Learnora empowers students and educators to engage with content more effectively.

---

## 🏆 Competition Context
This project was built for the **AWS Cendekiawan AI Competition 2026**.  
It showcases serverless architecture, cloud deployment, and practical application of AWS services.

---

## 🚀 Features
- User-Friendly UI/UX – Simple, modern interface for smooth navigation
- Course Management – Add, view, and organize learning modules
- Interactive Learning – Support for quizzes, notes, and progress tracking
- Cloud Deployment – Hosted on AWS (S3 for frontend, Lambda + API Gateway for backend)
- Scalable Architecture – Built with SAM for easy deployment and updates

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript (deployed via AWS S3)  
- **Backend:** AWS Lambda, API Gateway  
- **Infrastructure:** AWS SAM (Serverless Application Model)  
- **Version Control:** GitHub
